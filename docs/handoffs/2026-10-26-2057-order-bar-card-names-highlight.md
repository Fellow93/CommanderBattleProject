## What was done

**The user asked:**
- the order bar's formation cards read like "Cataphracts (Fellow)" for a player's formation;
- the selected formation highlighted better, its map icon too.

Built by an Opus agent; see `docs/plans/general-orders.md`, "As built: naming and highlighting the selection".

- **Card names:**
  - New `CommanderBattle.View/FormationNames.cs` holds `GetLabel`, a copy of the other session's `CommanderBattleAllyPlayerMarkersView.GetFormationLabel`; merge them later.
  - Player formations read "Cataphracts (Fellow)", AI formations the troop name only.
  - `CommanderBattleOrderUIHandler` sets each card's `OrderTroopItemVM.FormationName` every tick, only when it differs. Names are cached per slot and rebuilt on slot or side changes.
  - Our `Module/GUI/Prefabs/Order/OrderTroopItem.xml` replaces Native's and shows the name above the card: brush `CommanderBattle.Order.CardName`, up to two lines.
- **Selected card:** a gold glow behind the card when `IsSelected` (brushes `CommanderBattle.Order.Card.Selected.Melee/.Ranged`, added to `Module/GUI/Brushes/CommanderBattle.xml`).
- **Map icon:** new `CommanderBattleSelectedFormationView` + `SelectedFormationMarkersVM` + prefab `CommanderBattleSelectedFormationMarkers.xml`.
  - While the bar is open, it draws a gold ring (`formation_targeter_9`) around each selected formation's stock icon.
  - It reuses the stock icon view models read by reflection from `MissionGauntletFormationMarker._dataSource`; no ring if that field ever goes.
  - Registered in `CommanderBattleMissionViews` after the stock marker handler.
- **Key finding:** the stock order bar movie is compiled into Native's `TaleWorlds.MountAndBlade.GauntletUI.AutoGenerated` dlls, card included, so it never reads `OrderTroopItem.xml`.
  - `CommanderBattleOrderUIHandler.LoadBarFromXml` reloads just that movie with `UIConfig.DoNotUseGeneratedPrefabs` on for the one load.
  - It is checked every tick, because the stock handler reloads the compiled movie on joining a team and on an order type change.
- **Docs:** README (the order bar bullet, a "How it works" row, a checklist item) and the plan's as-built section.
